## Установка и запуск
1. **Склонируйте репозиторий:**
```bash
git clone <ссылка>
cd kursovoy
```
2. **Откройте папку проекта в Visual Studio Code.**

3. **Установите расширение Live Server:**
- Нажмите Ctrl+Shift+x
- Найдите "Live Server"
- Нажмите Установить

4. **Запустите проект:**
- Выберите любой html файл
- Откройте его с помощью Live Server

## Требования:
- Visual Studio Code
- Расширение Live Server
- Современный браузер
